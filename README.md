# FDA_meets_Economics
Repositorio de trabajo continuo dedicado a la integración del Análisis de Datos Funcionales (FDA, por sus siglas en inglés) en problemas de economía. El proyecto desarrolla modelos que combinan variables económicas con dinámicas de clima, explorando cómo los factores climáticos influyen en los comportamientos y resultados económicos a través de enfoques funcionales. El flujo de trabajo está dividido en dos etapas: la extracción y preparación de datos se realiza en Python, mientras que el análisis estadístico, el modelamiento FDA y la generación de resultados se llevan a cabo en R. El repositorio documenta los avances, scripts y metodologías del equipo, y sirve como espacio de colaboración para la investigación aplicada en la intersección entre economía, clima y análisis funcional de datos.
