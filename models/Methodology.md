# Model 1
## Model 1.1

$$
y_m = \alpha_c + \gamma_m + \int_0^K \beta(s) X_m(s) ds + \epsilon_m
$$

## Model 1.2

$$
y_m = \alpha_c + \gamma_m + \int_0^K \beta_1(s) X_{c,m}(s) ds + \int_0^K \beta_2(s) X_{v,m}(s) ds + \epsilon_m
$$

## Model 1.3

$$
y_m = \alpha + \gamma_m + \beta_1 \eta_{1,m} + \beta_2 \eta_{2,m} + \epsilon_m
$$

$\eta_m$ son los scores del multivariate fPCA, un script aparte será destinada a la estimación de este método
